# Untitled pixel-art tactical RPG (working repo)

Status: **pre-production: research complete, concept proposal awaiting
approval.** No game code yet. Start with `docs/PROJECT_STATE.md`.

This repository holds the research, design documents and production tools for
an original 2D pixel-art mobile tactical autobattler RPG. Its primary
*mechanical* reference is King God Castle. Characters, lore, art and UI are
all original.

| Path | Contents |
|---|---|
| `docs/PROJECT_STATE.md` | Handoff log: what exists, what was decided, next steps |
| `docs/design/00_concept_proposal.md` | Three concepts, the recommendation (working title **Hushlight**), and the direction |
| `docs/research_notes/` | Raw, cited research notes from each research workstream |
| `docs/reports/` | Synthesized research report |
| `docs/research/` | Environment constraints and the art feasibility spike |
| `tools/pixelforge/` | Text-grid sprite compiler and hue-shifted palette ramp builder |

The final concept, narrative premise and combat direction need approval
before any vertical-slice implementation begins.
